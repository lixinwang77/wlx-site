这是站点里的示例作品页，用来演示「作品」和「博客」如何分开。

## 这个项目想解决什么

- 有一个长期可更新的个人空间
- 博客负责文字，作品负责项目展示
- 部署尽量轻，不先养服务器

## 当前已具备

- 首页三入口：博客 / 作品 / GitHub
- 顶部胶囊导航
- 简介下方的社交图标栏
- Markdown 内容与标签筛选

把封面图、外链和正文替换成你的真实项目即可。
